# 🎓 StudyFlow — Персональний органайзер студента

Сучасний, адаптивний веб-додаток для організації навчання студента з **5 функціональними модулями**.

Працює повністю автономно (Client-side) — без стороннього бекенду, усі зміни зберігаються локально у браузері (`localStorage`).

---

## 🚀 5 Функцій для студента

1. **📅 Розклад занять**
   - Тижневий розклад пар (Понеділок – П'ятниця / Субота).
   - Відображення поточної та наступної пари у реальному часі (зі зворотним відліком).
   - Підтримка університетського паритету: **Чисельник (I) / Знаменник (II)** або щотижня.
   - Вказується тип заняття (лекція, практика, лаба), аудиторія та викладач.
   - Можливість роздрукувати розклад дня за допомогою кнопки «Друк».

2. **✅ Завдання та дедлайни (Тудуліст)**
   - Додавання завдань із встановленням пріоритетів (важлива 🔥, середня ⚡, низька ☕).
   - Автоматичне групування за дедлайнами: *Прострочені*, *Сьогодні*, *Цього тижня*, *Пізніше*, *Виконані*.
   - Швидке позначення виконання та видалення.

3. **⏱️ Фокус-таймер Pomodoro**
   - Інтервальний таймер навчання: 15 / 25 / 45 хвилин фокусу з налаштовуваними перервами.
   - Анімований SVG-індикатор кругового прогресу.
   - Звукове сповіщення (Web Audio API) після завершення сесії.
   - Аналітика за тиждень: кількість сесій, чисті хвилини фокусу та стовпчикова діаграма.

4. **🗂️ Навчальні картки (Flashcards)**
   - Колоди карток за темами (Веб-розробка, Бази даних, тощо).
   - Розумне інтервальне повторення: картки, які ви не запам'ятали, повертаються в кінець черги.
   - Підтримка гарячих клавіш: `Пробіл` — перевернути, `1` — «Не знаю», `2` — «Знаю».
   - Додавання власних колод та карток.

5. **🔥 Трекер щоденних звичок**
   - Сітка відміток за поточний тиждень.
   - Автоматичний розрахунок ланцюжка днів поспіль (streak).
   - Додавання власних звичок із вибором іконки та кольору.

---

## ⚙️ Додаткові можливості

- **Теми оформлення**: Темна та Світла тема з плавним перемиканням.
- **Резервна копія (Експорт / Імпорт)**: Збереження всіх ваших даних у JSON-файл та відновлення на іншому пристрої.
- **Скидання даних**: Можливість скинути стан до демонстраційних даних у будь-який момент.
